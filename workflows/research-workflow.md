# Research Workflow

Process to follow whenever the user gives a research topic. Applies to strategy,
foresight, leadership, and related professional topics for training content or
advisory work.

## Steps

1. **Topic Intake**
   User provides a topic (one line or a short brief).

2. **Clarifying Questions**
   Ask at least 3 clarifying questions before doing anything else. Always cover:
   - **Scope** — sub-questions to cover or exclude, breadth vs. depth
   - **Audience** — who reads this, and their existing familiarity with the topic
   - **Depth** — quick brief vs. full report; need for data, statistics, case studies
   Also ask, when relevant: application/context (training, client engagement,
   advisory), GCC/Kuwait relevance to prioritize, urgency/deadline.

3. **Written Plan**
   Propose a report structure tailored to this specific topic — do not reuse a
   fixed template, since structure varies by topic. Include: section headings,
   key questions the research will answer, estimated length. Do not start
   research yet.

4. **Approval**
   Wait for the user to approve or revise the plan before proceeding.

5. **Research**
   Research using web search plus any source material the user points to in
   `/resources`.

6. **Organize Findings**
   Write findings into the approved section structure. Short paragraphs, strong
   structure, practical framing, no filler, no unnecessary jargon.

7. **Save Outputs**
   - Save the final report to `/outputs` in **both Markdown and Word (.docx)**,
     same filename, different extensions.
   - File naming: lowercase, hyphenated, descriptive
     (e.g., `strategic-foresight-gcc-overview.md` / `.docx`).
   - Add a **Sources** section at the end of the report citing all sources used.
   - Save any raw source material worth keeping (articles, extracted text, data)
     into `/resources`, named to match the topic.

8. **Review Pass**
   Check the draft against the success criteria below before delivering.

## Success Criteria

Every report should be:

- Clear
- Actionable
- Accurate
- Contextualized (localized to Kuwait/GCC where relevant)
- Easy to understand
- Immediately useful

## Notes

- No fixed report template — structure is decided per topic in Step 3.
- Word version is generated automatically alongside the Markdown version every
  time, not on request.
